# Трудовые договоры

Организация открывает сайт, выбирает себя из списка (или сразу переходит по своей ссылке `…/#код`), вводит данные сотрудника и скачивает готовый договор в Word. Договор собирается в браузере, поэтому паспортные данные никуда не отправляются.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | сам сайт (общий шаблон договора уже встроен в него) |
| `companies.json` | список организаций с реквизитами |
| `templates/` | сюда кладутся отдельные шаблоны .docx, если они нужны какой-то организации |

## Как выложить на GitHub Pages

1. Создайте на GitHub репозиторий, например `dogovor`, и загрузите в него все файлы из этой папки (Add file → Upload files).
2. Откройте Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/dogovor/`.

## Как добавить или изменить организации

1. Откройте сайт, внизу главной нажмите «Управление списком организаций» (или зайдите по адресу `…/#admin`).
2. Добавьте или исправьте организации. Пока вы не выложите файл, изменения видны только вам.
3. Нажмите «Скачать companies.json» и загрузите этот файл в репозиторий вместо старого (Add file → Upload files).
4. Кнопка «Ссылка» копирует прямую ссылку для организации. По ней организация сразу попадает в свою форму, без выбора из списка.

## Свой шаблон для организации

Положите файл в папку `templates/`, например `templates/romashka.docx`, и в карточке организации укажите этот путь в поле «Свой шаблон». В шаблоне можно использовать только такие метки:

`{{ contract_number }} {{ city }} {{ contract_date }} {{ start_date }} {{ year }} {{ employer_title }} {{ employer_basis }} {{ employer_sign }} {{ work_address }} {{ position }} {{ salary_text }} {{ employee_fio }} {{ employee_birth }} {{ employee_doc }} {{ doc_date }} {{ doc_issuer }} {{ issuer_sp }} {{ employee_address }} {{ address_part }} {{ migration_line }} {{ employee_ids }} {{ employee_short }} {{ named }} {{ registered }} {{ received }}`

Проще всего взять за основу `templates/trudovoy_dogovor.docx` и поправить в нём текст. Каждую метку лучше вставлять целиком (скопировать и вставить), чтобы Word не разбил её на части.

## Важно

- Список организаций виден всем, у кого есть ссылка на сайт. Реквизиты ИП и ООО публичные (они есть в ЕГРЮЛ/ЕГРИП), но выбрать в списке можно любую организацию. Если нужно, чтобы каждая видела только себя, давайте организациям прямые ссылки. Список на главной можно отключить, это небольшая доработка.
- Проверка текста договора у юриста остаётся на вас.
